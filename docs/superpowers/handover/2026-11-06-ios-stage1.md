## How to check CI without a login

`gh` is not installed and job logs need a login. Use the public API:
- runs for a commit: `https://api.github.com/repos/NikkittaP/timeline-exporter/actions/runs?head_sha=<full sha>`
- jobs: `.../actions/runs/<run_id>/jobs`
- failure details: `.../check-runs/<job_id>/annotations` (written by `tools/ci_annotate.py`).
`ios.yml` is manual: it can only be started from the GitHub UI or API with a
token, so ask the owner to press "Run workflow" (mode `validate`) after the push,
or add a `push` trigger limited to `ios/**` and the workflow file for this stage.
